Exercícios de HTML

Os exercícios abaixo focam a estrutura básica de páginas web, elementos de texto, listas, hiperligações, imagens e formulários.

b) Indique a finalidade da tag <!DOCTYPE html> num documento HTML5.

HTML 2 – Estrutura mínima (prático)

HTML 3 – Listas e links (misto)

Considere que pretende criar um menu simples com 3 ligações: "Início", "Sobre" e "Contacto".

a) Que tipo de lista é mais apropriada para um menu de navegação? Justifique.

b) Escreva o código HTML para esse menu, assumindo que as páginas são index.html, sobre.html e contacto.html.

HTML 4 – Imagens e atributos (prático)

Escreva o código HTML para inserir uma imagem chamada logo.png, com texto alternativo "Logótipo da disciplina" e largura de 200px.

HTML 5 – Formulário simples (misto)

Gabarito – HTML
  • HTML 1: <head> é a secção onde colocamos informação sobre a página (como título no separador, ligações para ficheiros CSS/JS e metadados) e normalmente não aparece no ecrã. <body> é a parte visível: tudo o que o utilizador vê (textos, imagens, botões, formulários, etc.). A declaração <!DOCTYPE html> informa o navegador de que o documento segue o padrão HTML5, para que interprete o código de forma correta e consistente.
  • HTML 2: O documento mínimo em HTML5 deve ter: <!DOCTYPE html>, <html lang="pt">, um <head> com pelo menos um <meta charset="UTF-8"> e o <title>Portal PTP I</title>, e um <body> que contenha um único <h1>Bem-vindo ao Portal de Exercícios</h1>.
  • HTML 3: Para menus de navegação, é comum usar uma lista não ordenada (<ul>) com itens <li>, porque representa um conjunto de opções sem ordem numérica. Dentro de cada <li> colocamos um link <a href="...">, apontando para index.html, sobre.html e contacto.html.
  • HTML 4: A imagem deve ter o atributo src (ficheiro), alt (texto alternativo para acessibilidade) e o atributo de largura, por exemplo: <img src="logo.png" alt="Logótipo da disciplina" width="200">.
  • HTML 5: O formulário deve ter a tag <form> a envolver os campos, inputs de texto para "Nome" e "Email" com o atributo required e um botão de submissão, por exemplo <button type="submit">Enviar</button>. É boa prática usar <label> associados a cada campo.
Gabarito – CSS
  • CSS 1: CSS inline é escrito diretamente no elemento através do atributo style, o que dificulta a manutenção. CSS interno é colocado dentro de uma tag <style> no <head>. CSS externo fica num ficheiro separado (.css) ligado ao HTML com <link>. Usar ficheiros externos facilita a reutilização de estilos em várias páginas e permite que o browser faça cache, melhorando o desempenho.
  • CSS 2: Para o título: #titulo-principal { color: #002b5c; }. Para o parágrafo em destaque: p.destaque { font-weight: bold; }. Aqui usamos um seletor de id (#) e um seletor de classe (.).
  • CSS 3: O box-model é composto por: conteúdo (content), preenchimento interno (padding), borda (border) e margem externa (margin). Um exemplo de regra completa seria: .caixa { width: 300px; padding: 16px; margin: 24px; border: 2px solid #ccc; }, definindo a largura da área de conteúdo e os espaços à volta.
  • CSS 4: Podemos definir o estilo global da página com: body { font-family: "Segoe UI", Arial, sans-serif; font-size: 16px; color: #222; background: #f5f7fb; }. Assim garantimos tipografia consistente e bom contraste entre texto e fundo.
  • CSS 5: Para ativar o flexbox, usamos display: flex; no elemento pai. Para uma barra de navegação com itens na mesma linha e espaço entre eles, por exemplo: .nav { display: flex; justify-content: space-between; align-items: center; }.
Gabarito – JavaScript
  • JS 1: let e const têm escopo de bloco (respeitam chaves {}), enquanto var tem escopo de função ou global. const não permite reatribuição do valor (a referência não muda). Exemplos: let idade = 20;, const PI = 3.14;, var nome = "Ana";.
  • JS 2: A função classificarNota deve receber um número e usar instruções if / else if / else para testar os intervalos. Por exemplo, se a nota for menor que 10, devolve "Reprovado"; se estiver entre 10 e 13, "Suficiente"; 14 a 17, "Bom"; 18 a 20, "Excelente".
  • JS 3: Podemos usar um ciclo for de 0 até 20, verificando se o número é par com i % 2 === 0 e, em caso afirmativo, escrever no console com console.log(i). Alternativamente, podemos incrementar de 2 em 2: for (let i = 0; i <= 20; i += 2) {...}.
  • JS 4: A função media deve somar todos os elementos do array (por exemplo com um ciclo ou reduce) e depois dividir pelo número de elementos (array.length). É importante verificar o caso de array vazio, devolvendo 0 ou outra indicação apropriada para evitar divisão por zero.
  • JS 5: O código deve obter as referências aos elementos com document.getElementById, registar um addEventListener("click", ...) no botão e, dentro da função, ler txt-nome.value. Em seguida, deve construir uma mensagem de saudação (por exemplo, "Olá, Ana!") e atribuí-la à propriedade textContent da div com id resultado.
